# Misión

Este proyecto web centraliza la generación de cotizaciones y cuentas de cobro para un negocio de soldadura, con acceso restringido, presentación clara y trazabilidad documental.

## Qué construimos

Una aplicación web privada que permite iniciar sesión, navegar por un menú principal, elaborar cotizaciones, elaborar cuentas de cobro, exportar cada documento a PDF y consultar el historial de cuentas de cobro.

## Productos funcionales

1. **Acceso autenticado** — pantalla de inicio de sesión con validación de usuario y contraseña contra la base de datos.
2. **Menú principal** — acceso visual a los formularios principales del sistema.
3. **Cotización** — formulario para diligenciar datos del cliente, productos o servicios, calcular totales y exportar el documento a PDF.
4. **Cuenta de cobro** — formulario con consecutivo único, cálculo de totales, abonos, saldo pendiente, actualización del saldo y exportación a PDF.
5. **Historial de cuentas de cobro** — listado consultable de cuentas generadas con posibilidad de búsqueda y descarga de documentos.

## Para quién

- Dueño del negocio, que necesita generar cotizaciones y cuentas de cobro de forma ágil.
- Contadora, que necesita consultar el historial y verificar el estado de las cuentas de cobro.

## Principios

- **Sencillo** — la interfaz debe ser intuitiva y reducir al mínimo los campos ambiguos.
- **Seguro** — el acceso debe quedar restringido a usuarios autorizados.
- **Auditable** — el consecutivo de cuentas de cobro no debe perderse y el historial debe poder consultarse.
- **Consistente** — la documentación, la interfaz y el flujo funcional deben mantener el mismo criterio en todo el proyecto.

## Qué NO es

- No es una web pública de libre acceso.
- No es un comercio electrónico.
- No es un sistema contable completo; solo cubre cotizaciones, cuentas de cobro e historial asociado.
