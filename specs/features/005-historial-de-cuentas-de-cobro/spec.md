# **005 · Historial de cuentas de cobro**

**Estado:** en definición

## Qué hace

El usuario puede ver el listado histórico de cuentas de cobro generadas, buscar o filtrar registros, abrir un documento existente y descargar su PDF. También puede editar una cuenta para registrar un abono adicional o dejar saldo en cero cuando el pago se complete.

## Por qué

Esta pantalla permite consultar el historial del negocio y dar seguimiento a cuentas pendientes sin perder la trazabilidad de cada registro.

## Criterios de aceptación

- [ ] muestra un listado de cuentas de cobro con su fecha o referencia temporal
- [ ] permite buscar o filtrar registros del historial
- [ ] permite abrir un registro para ver su detalle
- [ ] permite descargar el documento en formato PDF desde el historial
- [ ] permite editar una cuenta de cobro para registrar un abono o el pago final del saldo
- [ ] conserva la información visible en español
- [ ] funciona de forma responsive en escritorio y dispositivos móviles

## Fuera de alcance

- No incluye creación de cuentas nuevas.
- No incluye acceso público sin autenticación.
- No incluye edición masiva de registros.
